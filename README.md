# AI-AutoFlow
AI-AutoFlow là hệ thống AI tự động hóa trên Windows 11 Pro, kết nối Linear, Codex, GitHub và OpenAI thành một quy trình thống nhất. Hệ thống hỗ trợ quản lý công việc, phát triển mã nguồn, thực thi tác vụ, kiểm tra kết quả, MCP, Windows Executor, tự động hóa theo lịch và mở rộng tích hợp các dịch vụ được cấp quyền.
